# 窝囊版（萌宠乐园模式）实施计划

## 概述

在现有「灵魂碎片 / Monkey Business」恐怖迷宫游戏基础上，新增一个**萌宠乐园风**的「窝囊版」模式。通过主菜单切换，同一份代码、两套资源表现。恐怖元素被替换为可爱、明亮、无惊吓的体验，方便不能接受恐怖元素的玩家游玩。

### 已识别的恐怖元素清单
1. **血猴模型**：红眼/红光信标/獠牙/深红毛皮（enemy.js `_buildModel`）
2. **扑脸 jumpscare**：被抓时冲脸特写动画（enemy.js `startFaceLunge`/`holdJumpscarePose`/`frameCameraOnFace`，game.js `_lose`/`_loop` CAUGHT 分支）
3. **黑暗氛围**：深色背景 0x1a1210、浓雾 FogExp2、暗调环境光（scene.js）
4. **血迹**：走廊地面的暗红血斑（world.js `_addBloodStain`/`_matBlood`）
5. **恐怖音频**：心跳、低频 drone、追逐锯齿波、吼叫、被抓刺耳音（audio.js）
6. **恐怖文案**：菜单「CONTENT WARNING · 恐怖内容提示」☠、被抓「被抓住了」/「Murder Monkey 撕碎了你」、HUD「！被发现了！」
7. **被抓过场动画**：血色刀光闪屏/红色暗角/噪点（index.html `#caught-screen`、style.css `.caught-*`）
8. **平衡压力**：回家时再刷 6 只同速猴子封路（game.js `_spawnEscapeMonkeys`）

## 设计决策

- **模式存储**：`localStorage` 键 `dd-mode`，值为 `'classic'`（默认）或 `'cute'`
- **传递方式**：`Game` 构造时读取并存为 `this.mode`，传入 `Enemy`/`World`/`AudioSystem`/`UI` 的 options；Scene 直接在 `Game._initLevel` 里按 mode 调用 `setBrightness`/雾色方法
- **保持核心玩法**：迷宫/收集/躲避/逃脱不变，仅替换观感与平衡参数
- **不上榜区分**：窝囊版成绩也可上榜单，但内部记录带 `mode:'cute'` 字段（本次仅预留字段，不强制改榜单展示，避免过度改动）

## 实施改动

### 1. 新增模式配置模块
**新建文件 `js/mode.js`**（集中定义两种模式的参数，避免散落硬编码）
- 导出常量 `MODE = { CLASSIC: 'classic', CUTE: 'cute' }`
- 导出 `getCuteConfig()`：返回窝囊版参数对象（颜色/速度/文案/音效开关等）
- 导出 `loadMode()` / `saveMode(mode)`：localStorage 读写

### 2. 主菜单加模式切换 — index.html + ui.js + game.js
- **index.html**：在 `#menu .login-panel` 上方插入模式切换器：
  ```html
  <div class="mode-switch" role="tablist" aria-label="游戏版本">
    <button id="mode-classic" class="mode-btn active" role="tab">经典版</button>
    <button id="mode-cute" class="mode-btn" role="tab">窝囊版</button>
  </div>
  ```
- **style.css**：加 `.mode-switch`/`.mode-btn` 样式（圆角药丸，激活态高亮）
- **ui.js**：新增 `setMode(mode)` 方法，更新按钮激活态；构造时绑定按钮 click 事件，调用回调
- **game.js**：
  - 构造时 `this.mode = loadMode()`
  - 菜单按钮回调 → `saveMode(mode)` + `this.mode = mode` + 同步 UI
  - `_initLevel` 把 `this.mode` 透传给 Enemy/World/Audio/UI 的 options
  - 经典版菜单显示 `.warning-horror`；窝囊版隐藏恐怖警告、改显示「窝囊版 · 萌宠乐园」轻量提示卡

### 3. 敌人萌宠化 — enemy.js
- `_buildModel()` 根据 `this.mode` 分支：
  - **cute 模式**：橘猫造型
    - 毛色 `0xff9933`（橘）、肚皮 `0xfff0e0`（白）、绿眼 `0x66cc44`（无 fog:false 红光、改为小黑点眼珠）
    - 无獠牙、无头顶红色信标、无红色 PointLight（改加一个柔和的暖白 PointLight `0xffd0a0` 强度 0.6）
    - 加两只三角形耳朵（橘色 + 内耳粉色 `0xffaaaa`）
    - 加粉色小鼻子 `0xff9999`
  - **classic 模式**：保持原血猴造型不变
- 移速参数：cute 模式 `patrolSpeed=1.4`、`huntSpeed=2.6`（玩家 walk=2.5/run=4.6，可轻松甩开）、`viewDistance=10`、`catchDistance=1.3`
- **扑脸动画替换**：cute 模式下 `startFaceLunge` 不播 jumpscare，改为「慢速走过来蹭镜头」：
  - `duration` 拉长到 3.0s
  - `toScale` 降到 1.2（不放大吓人）
  - 不强制镜头对脸特写；`holdJumpscarePose` 改为「坐着歪头」姿态
- 构造函数接收 `options.mode`，存为 `this.mode`

### 4. 世界去恐怖化 — world.js + scene.js
- **world.js**：
  - `_buildDecorations()`：cute 模式跳过 `_addBloodStain` 调用（血迹全去掉）
  - 可选：cute 模式把 `_matPaintCanvas` 暖色调换成更明亮的粉/绿/蓝系（保持低成本，仅换色值数组）
  - 接收 `options.mode`，存为 `this.mode`
- **scene.js**：
  - 新增 `setMode(mode)` 方法：
    - cute：`scene.background = 0x9fd8ff`（天蓝）、`fog = FogExp2(0xb8e0ff, 0.018)`（淡蓝薄雾）、环境光提到 `0x88aaff` 强度 1.4、曝光 `toneMappingExposure = 1.4`
    - classic：恢复原 0x1a1210 / 0x1e1614 / 0.038 / 0.95 / 1.15
  - `Game._initLevel` 在创建 Scene 后立即调用 `this.scene.setMode(this.mode)`
  - 同时把 `_baseAmbient`/`_baseHemi`/`_baseFlash` 按 mode 调整，使 `setBrightness` 仍能正确缩放

### 5. 音频软化 — audio.js
- 构造接收 `options.mode`，存为 `this.mode`
- **cute 模式**：
  - `startAmbient()`：把低频 drone 振荡器频率提到 `220Hz`/`277Hz`（大三和弦感）、增益减半、噪声层换为高通 800Hz 的轻「风铃」感
  - `playMonsterRoar()`：改为短促的「喵」声 —— 锯齿波换正弦波，频率 `500→800Hz` 快速上滑 0.15s，时长缩短
  - `playCaught()`：换成下行小琶音（三角波 `600→400→300Hz`），不刺耳
  - `playSpotCue()`：换成轻「叮」一声（正弦 `1200Hz` 0.1s）
  - 心跳系统：cute 模式 `setHeartbeatByDistance` 直接 return（不播心跳），避免紧张感
  - 追逐层 `startChaseLayer`：cute 模式不启动（`setThreatLevel` 在 cute 模式 return）
  - 保留 `playShardCollect`/`playWin`/`playExitOpen`/`playElevatorDing`（已是中性音效）

## 假设与决策

- 假设用户希望「最小侵入式」实现：经典版体验完全不变，所有改动通过 `this.mode` 分支隔离
- 决策：不新建独立项目，不复制资源文件；同一套代码 + 同一套模型几何，仅材质/参数/文案分支
- 决策：保留光敏性癫痫警告（cute 模式仍有闪烁/快速镜头移动，安全合规需要）
- 假设：localStorage 键名 `dd-mode` 不与现有 `dd-monkey-settings` 冲突
- 决策：榜单本次不做 mode 字段展示改造，仅在 `auth.submitRun` 调用时附带 `mode` 字段（若 auth.js 支持则传，否则忽略），避免扩大改动面

## 验证步骤

1. **启动游戏**：`python -m http.server 8000` 或运行 `start.bat`，浏览器打开
2. **菜单切换**：主页可见「经典版 / 窝囊版」切换按钮，点击后按钮激活态切换、恐怖警告 ↔ 萌宠提示卡互换
3. **经典版回归测试**：切到经典版开始游戏，确认血猴/血迹/扑脸/心跳/恐怖文案全部与改动前一致
4. **窝囊版视觉**：切到窝囊版开始游戏，确认
   - 场景变亮、雾变淡蓝、背景天蓝
   - 走廊无血迹
   - 敌人为橘猫造型（无红眼/无信标/无红光）
5. **窝囊版音频**：靠近敌人不播心跳、不播追逐锯齿波；喵声替换吼叫；被抓音效为下行小琶音
6. **窝囊版被抓过场**：被抓时无血色刀光闪屏，改为柔和动画；文案「被抱住了」「小橘猫黏住了你」
7. **窝囊版平衡**：敌人明显更慢、更少，玩家可轻松通关；集齐碎片回家提示文案为萌宠风
8. **刷新持久化**：刷新页面后模式选择保留（localStorage）
9. **控制台验证**：`window.__game.mode` 应正确反映当前模式
